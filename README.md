# 📋 Sistema Kanban de Licitações

**Sistema completo para gerenciamento de processos licitatórios**

🌐 **Site:** https://Frutuoozo.github.io/Licitacao-Kanban

---

## 🚀 DEPLOY RÁPIDO (3 comandos)

```bash
# 1. Instalar dependências
npm install

# 2. Fazer deploy
npm run deploy

# 3. Ativar GitHub Pages
# Vá em: https://github.com/Frutuoozo/licitacao-kanban/settings/pages
# Branch: gh-pages → /root → Save
```

---

## 💻 Rodar Localmente

```bash
npm install
npm start
```

Abre em: http://localhost:3000
