## Configuração

O frontend usa `REACT_APP_API_URL` para acessar a API e o Socket.IO. Copie
`frontend/.env.example` para `frontend/.env` durante o desenvolvimento ou
configure essa variável no serviço de build em produção.

O backend usa as variáveis de `backend/.env.example`. Em produção, defina
`FRONTEND_URL` com a origem pública do frontend. Mais de uma origem pode ser
informada separando os endereços por vírgula.

Quando o frontend estiver publicado em HTTPS, a API e o Socket.IO também
precisam estar disponíveis em HTTPS para que o navegador não bloqueie as
requisições.

## Publicação

1. Publique o backend em um serviço Node.js com as variáveis do ambiente e um banco MySQL acessível.
2. Configure `FRONTEND_URL` no backend com a URL final do frontend.
3. Configure `REACT_APP_API_URL` no frontend com a URL pública do backend.
4. Execute `cd frontend && npm run build` e publique a pasta `frontend/build`.
