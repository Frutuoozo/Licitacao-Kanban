## 🚀 Deploy no Vercel

O frontend pode ser publicado no Vercel com os seguintes passos:

1. Crie um projeto no Vercel e conecte este repositório.
2. Defina a pasta de projeto como `frontend`.
3. Configure a variável de ambiente no Vercel:
   - `REACT_APP_API_URL=https://seu-backend-em-producao.com`
4. O build será executado automaticamente com `npm run build`.

> Se a API estiver em outro host, lembre-se de também configurar o CORS no backend para aceitar esse domínio.
