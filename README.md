** 📋 Sistema Kanban de Licitações

https://github.com/FrutuoozoSistema completo para gerenciamento de processos licitatórios**, com organização visual em quadro Kanban, controle de modalidades, prazos e documentos.

🌐 **Site:** [LicitKanban](https://Frutuoozo.github.io/Licitacao-Kanban)   
🔧 **API/Backend:** Render
🗄️ **Banco de dados:** PostgreSQL (Nuvem Adiven)

---

## 🛠️ Tecnologias

- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js / Express (hospedado sem renderização)
- **Banco de dados:** PostgreSQL (Nuvem Adiven)

---

## 📦 Funcionalidades

✅ Sistema Kanban completo (arrastar e soltar entre colunas)
✅ 7 modalidades de licença  
✅ Salvamento automático
✅ Design responsivo (desktop e mobile)

---

## 🚀 Como rodar localmente

```batedor
clone git https://github.com/Frutuoozo/Licitacao-Kanban.git
cd Licitacao-Kanban/frontend
instalação do npm
início do npm
```
